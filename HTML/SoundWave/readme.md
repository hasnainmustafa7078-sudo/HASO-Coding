## Project Description

SoundWave is a modern single-page music website designed for
discovering songs and artists.

The website includes a responsive navigation bar, hero section,
about section, music collection, featured artist section,
YouTube-based music player, search functionality, contact form,
and footer.


## Main Features

- Responsive Bootstrap Navbar
- Hero Section
- About Section
- 7 Music Cards
- YouTube Music Player
- Play Song Functionality
- Previous / Next Song
- Replay Function
- Music Search / Filter
- Featured Artist
- Contact Form Validation
- Responsive Design
- Hover Animations
- Mobile Friendly Layout

## How to Run

1. Open the SoundWave folder.
2. Open index.html in a web browser.
3. Make sure the css and js folders remain inside the project folder.
4. Internet connection is required for Bootstrap CDN, Google Fonts,
   Bootstrap Icons and YouTube videos.
