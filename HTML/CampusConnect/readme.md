CampusConnect is a Responsive single-page web application designed for college students and faculty to explore, search, filter, and view upcoming campus events, cultural nights, Picnic Events and Sports Tournaments.



Built completely with Vanilla **HTML5**, **CSS3**, **JavaScript** (ES6+), and JSON without any external JavaScript frameworks or heavy libraries.

Features
-Single Page Application (SPA) Navigation: Smooth switching between Home, About Us, Event Catalog, Gallery, Feedback, and Contact pages without         

full browser reloads.

\-Dynamic Event Catalog: Loads event data dynamically from a structured JS/JSON source file (events.js).

\-Real-time Search & Filtering: Filter events by category (Technical, Cultural, Sports) or search directly by event title.

\-Sorting Capabilities: Sort events by event date or alphabetically by title.

\-Interactive UI & Animations: Built with modern CSS Flexbox/Grid, Google Poppins font, card elevation, image zoom effects, and fade-in animations.

\-Feedback Form : Interactive interface for students and faculty to submit reviews and feedback.

\-Responsive Layout: Clean display across desktop, tablet, and mobile browsers.





Tech Stack & Technologies Used



\-Frontend: HTML5, CSS3 (Flexbox & Grid Layouts)

\-Typography: Google Fonts (Poppins)

\-Scripting: Vanilla JavaScript (ES6+)

\-Data Storage: JavaScript Data Structure (events.js)


Project Structure



│

├── index.html       Main HTML document containing all page section structures

├── style.css        Complete CSS styles, Poppins font import, layouts \& animations

├── events.js        Event data array (ID, Title, Category, Date, Venue, Images)

├── script.js        Main application logic (Navigation, Rendering, Search, Filtering)

└── README.md        Project documentation \& team information
